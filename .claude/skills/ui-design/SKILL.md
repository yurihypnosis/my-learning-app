# UI デザイン ── 静かな計器（Quiet Instrument）

このアプリは **資格合格を目指す成人の自己学習者**（＝オーナー本人）のためのもの。
デザインの唯一の判断基準はこれ:

> **ユーザーが本質的に知りたいのは「受かるのか。前に進めているのか。」それだけ。**

装飾ではなく、この問いに静かに答えることに全リソースを注ぐ。

## 絶対原則（迷ったらここに戻る）

1. **問いはひとつ。** 1画面につき主役は1つ。合格ラインへの軌道、到達度、次の一手 ── どれか1つを大きく置き、他は全部それを支える脇役に落とす。
2. **盛らない。** 要素を足したくなったら、まず何かを消せないか考える。情報密度が上がった瞬間、この製品は安っぽくなる。
3. **数字と余白で語る。** 色・発光・アイコンで盛るのではなく、タイポグラフィの階層と余白で階層を作る。
4. **ゲーム要素は囁く、叫ばない。** レベル・連続日数・XP は消さないが、脚注として小さく1行に畳む。主役に絶対しない。

## やってはいけない（＝過去の失敗＝「ダサいソシャゲ」化）

- 🔥 炎・👑 王冠・🎯 などの**絵文字アイコン**を UI 部品に使う
- **金グラデーションのメダル**、勲章棚をホームに並べる
- ネオン発光（`box-shadow` で光らせる）、彩度マシマシの色
- 極太ウェイト（`font-weight:800`）の巨大数字 → カジノ感
- チップ／ピル／バッジを画面中に散らす、`rounded` を全要素に
- 1画面に指標を詰め込む（レベル＋XP＋ストリーク＋ノルマ＋カウントダウン＋バッジ…の全部盛り）
- 参加ボーナス的な報酬（「開いたで +10XP」）。**逆に内発的動機を下げる**

## やること

- **大きな数字は細ウェイト**（`font-weight:200〜300`）＋ `letter-spacing:-.03em` ＋ `font-variant-numeric:tabular-nums`。計器の静けさを出す
- ラベルは小さく（11px前後）`letter-spacing:.16〜.22em; text-transform:uppercase; color:muted`
- 罫線は極細のヘアライン（`rgba(255,255,255,.05〜.08)`）。ボックスで囲うより線1本で仕切る
- **報酬 = 学習成果に連動**。数字が動く瞬間（合格確率 61→67 のカウントアップ、合格ライン突破）そのものがご褒美。派手なエフェクトは要らない
- **まぐれ当たり（確信度3の正解）は加算しない** ── 既存ロジックの思想を全報酬設計へ拡張。「理解して正解した分だけ伸びる」
- 意味のある達成のみ静かに祝う（「弱点を10問克服」を控えめな1行で）。棚に並べない
- アニメーションは最小限・上品に（軌道の描画、数字のカウント）。`prefers-reduced-motion` を必ず尊重

## デザイントークン（`src/app/globals.css` の `@theme` が唯一の正）

新しい色を勝手に増やさない。まずこの変数を使う。

| 用途 | 変数 / 値 |
|---|---|
| 地 | `--color-bg` `#0f1117` |
| カード | `--color-card` `#1a1d27` / `--color-card2` `#141720` |
| 罫線 | `--color-border` `#2a2f3f` / `--color-border2` `#3a4050` |
| 文字 | `--color-fg` `#e8eaf0` / muted `--color-muted` `#8892a4` / faint `--color-muted2` `#555e70` |
| アクセント | `--color-primary` `#3b82f6` / `--color-primary2` `#60a5fa` |
| フォント | `--font-sans` = Noto Sans JP |

- **アクセントは青1色に集中。** 大胆さを使うのは1画面1箇所だけ。
- **セマンティック色はアクセントと別軸**で最小限に: 合格圏＝落ち着いた緑（`#6ab08d` 程度、彩度控えめ）、ギリギリ＝琥珀、危険＝赤。多用しない。
- モックアップ（Artifact）では発光を落とし、緑もこの低彩度トーンを使うと計器らしくなる。

## 実装メモ

- ダーク固定（`color-scheme: dark`、`html` に既定）。ライトテーマは無い。
- スタイルは Tailwind v4 ユーティリティ＋動的値の inline `style`。トークンは Tailwind クラス（`bg-card` `text-muted` `border-border` 等）で参照できる。
- 合格ライン軌道・到達度・XP・連続日数は **`answer_events` + `user_question_progress` から導出可能**。まず新テーブル無しで実装する（永続状態が要るのは「ストリークフリーズ」等の保険を入れる時だけ）。
- 参照実装の素: `src/lib/quiz/readiness.ts`（`projectedAtExam` 等）、`stats.ts`（`masteryFromProgress` / `passProb`）、`log-client.tsx`（`calcStreak`）。

## リファレンス

目指す肌触りは **Oura / Whoop / Linear / Things** の落ち着いた高級感。Duolingo 的な派手さではなく、静かな計器。
2026-07 に本スタイルを確立（ゲーミフィケーション案 v2）。「盛った v1 はダサい／v2 の静けさが正解」というオーナーの判断が起点。
